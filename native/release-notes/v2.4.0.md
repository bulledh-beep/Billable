- **Your own tools in every chat.** Agents → Tools lists the MCP servers Claude Code and Codex load on this Mac, with a live connected dot, and lets you add or remove one.
- **Copy from the Claude app.** Servers and extensions you installed in the Claude app, like DaVinci Resolve or Control Chrome, copy to Claude Code and Codex in one tap.
- **Computer use.** Agents can look at your screen, open apps, click, scroll and type. Each chat asks before it sees your screen and before it uses each app, and only one chat uses the screen at a time.
- **Attach anything.** Add files, folders, screenshots and documents to a message with +, by pasting, or by dropping them on the box. Pictures go to the agent as images. From the website and your phone, attachments upload and the Mac fetches them.
- **@ and /.** Type @ to pick a file from the chat's folder, and / for your Claude Code commands and skills.
